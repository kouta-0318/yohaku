Yohaku 利用規約

最終更新日：2026年8月22日

本利用規約（以下「本規約」といいます。）は、Yohaku運営者 Kota Saito（以下「当方」といいます。）が提供するアプリケーション「Yohaku - 瞑想・呼吸・ゲーム」（名称または内容が変更された場合は、変更後のアプリケーションおよび関連サービスを含み、以下「本アプリ」といいます。）の利用条件を定めるものです。

ユーザーは、本規約の内容を確認し、同意したうえで本アプリを利用するものとします。

第1条（本規約の適用）

  1. 本規約は、本アプリの利用に関するユーザーと当方との間の一切の関係に適用されます。
  2. 当方が本アプリ内、Webサイト、App Storeその他の場所に掲載する注意事項、利用方法およびルールは、本規約の一部を構成します。
  3. App Storeの利用、アプリのライセンスおよび購入には、Apple Inc.が定める規約その他の条件も適用されます。
  4. 本規約と個別の案内に矛盾がある場合は、当該案内に別段の定めがない限り、本規約が優先して適用されます。

第2条（本アプリの目的）

  1. 本アプリは、瞑想、呼吸、ゲームその他のマインドフルな活動の実行、記録および振り返りを支援するアプリです。
  2. 本アプリは、ユーザーを評価または採点することを目的とするものではありません。
  3. 本アプリは、短い時間から自分自身へ意識を向け、日々の実践や変化を記録する機会を提供することを目的としています。
  4. 本アプリで提供する活動、音声、環境音、記録、分析、通知その他の機能は、追加、変更または終了される場合があります。

第3条（利用条件）

  1. ユーザーは、自身の状況を考慮し、自己の責任において本アプリを利用するものとします。
  2. 未成年者が本アプリを利用する場合は、必要に応じて親権者その他の法定代理人の同意を得てください。
  3. 本アプリの利用に必要な端末、通信環境、Apple Account、iCloudその他の環境は、ユーザーの責任で準備および管理するものとします。

第4条（活動記録および主観的な評価）

  1. 本アプリでは、活動の種類、実施日時、実施時間、実施回数および完了状態等の記録が保存される場合があります。
  2. 活動終了後の主観的な評価および自由記述メモの入力は任意です。これらを入力しなかった場合でも、完了した活動の記録が保存される場合があります。
  3. 主観的な評価は、ユーザーがその時点の状態を振り返るための目安であり、医学的、心理学的または客観的な測定結果を示すものではありません。
  4. 当方は、本アプリの改善、機能追加またはコンセプトの変更等に伴い、評価項目、名称、尺度、入力方法、集計方法、分析方法および表示方法を変更することがあります。
  5. 過去の評価記録は、原則として記録時点の項目および尺度に基づく情報として取り扱います。異なる時期または異なる指標の評価が、常に換算または直接比較できることを保証するものではありません。
  6. 記録の意味または取扱いに重要な変更がある場合、当方は、本アプリ内、Webサイト、App Storeその他の適切な方法で周知します。

第5条（無料機能およびPremium機能）

  1. 本アプリでは、無料で利用できる機能と、有料プランで利用できるPremium機能を提供する場合があります。
  2. Premium機能の内容、対象機能、価格、利用期間および無料体験の有無は、本アプリ内またはApp Storeの購入画面に表示します。
  3. 無料機能とPremium機能の区分、内容および提供条件は、本アプリの改善や運営上の必要に応じて変更される場合があります。
  4. ユーザーへ重大な影響を与える変更を行う場合、当方は、変更内容に応じて合理的な方法で事前に周知します。
  5. 本規約は、将来追加されるすべての機能が無料またはPremiumのいずれかとして永続的に提供されることを保証するものではありません。

第6条（サブスクリプション）

  1. Premiumは、App Storeを通じた自動更新サブスクリプションとして提供される場合があります。
  2. サブスクリプションの価格、期間、無料体験、適用条件および更新日は、購入時に表示されるApp Storeの購入確認画面の内容が優先されます。
  3. 無料体験または割引の適用可否は、Apple Inc.の購入履歴その他の条件に基づいて判定されます。すべてのユーザーに無料体験または割引が適用されるとは限りません。
  4. ユーザーが更新日前にサブスクリプションを解約しない場合、選択したプランが自動的に更新され、Apple Accountに料金が請求されます。
  5. 解約後も、原則として現在の利用期間が終了するまではPremiumを利用できます。
  6. サブスクリプションの管理、更新停止、解約および返金は、Apple Inc.が定める方法に従います。当方は、Apple Inc.の手続による場合を除き、解約、返金または請求停止を直接処理することはできません。
  7. アプリを削除しただけでは、サブスクリプションは解約されません。

第7条（記録データの取扱い）

  1. 本アプリで作成された活動記録、主観的な評価、メモおよび設定等は、ユーザーの端末内またはユーザー自身のiCloud環境に保存される場合があります。
  2. ユーザーが入力したメモその他の情報に関する権利は、ユーザーに帰属します。
  3. 当方は、ユーザー個人の活動記録、主観的な評価およびメモを常時閲覧することを目的とした仕組みを設けません。
  4. ユーザーが問い合わせ対応のために記録、スクリーンショットまたは診断情報等を当方へ送信した場合、当方は問い合わせ対応に必要な範囲でこれらを確認および利用します。
  5. ユーザー情報の取扱いについては、別途定めるプライバシーポリシーに従います。

第8条（iCloud同期およびバックアップ）

  1. 本アプリは、記録データをユーザー自身のiCloud環境へ同期する機能またはバックアップを作成、復元する機能を提供する場合があります。
  2. iCloud同期は、Apple Account、iCloud設定、通信環境、空き容量、端末設定およびApple Inc.のサービス状況等により、遅延または失敗する場合があります。
  3. 当方は、すべての記録が常に同期されること、または記録が消失しないことを保証しません。
  4. ユーザーは、必要に応じて本アプリ内の記録を確認し、利用可能なバックアップ機能を使用して自身の記録を管理するものとします。

第9条（HealthKit連携）

  1. 本アプリは、ユーザーが明示的に許可した場合に限り、対象となる活動時間をAppleヘルスケアのマインドフル時間として記録する場合があります。
  2. HealthKitへの記録対象は、マインドフルな実践として設計された活動に限られ、すべての活動が記録されるとは限りません。
  3. 本アプリは、HealthKitに書き込む情報またはHealthKitから取得する情報を、広告、販売または不適切な第三者提供の目的で使用しません。
  4. ユーザーは、Appleヘルスケアまたは端末設定から、いつでもHealthKitの許可を変更または取り消すことができます。

第10条（外部サービス）
